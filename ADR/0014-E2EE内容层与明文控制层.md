# ADR 0014：E2EE 内容层与明文控制层（房间号公开 + 密钥 fragment）

- Storage：密钥**不落盘在这条链路上**（内存 / URL fragment）；密文随普通事件走中继
- Decision owner：Zcode（V5-2 任务 2.4 施工方）
- Reviewed by：**待 Qoder 只读审计 + 人工评审签收**

  · **附件/大内容**（引用通道里那份本体）的加密：现在只定义了事件内容层；
  引用指向的字节是否加密、谁来存，随内容层（V6 划布事件化）一起定；

  链接形态与"密钥塞 query 取不到"）；`engine/sync/relay.ts`（密文与明文在它眼里没有区别 —— 它不解释 payload）。
- 外部参照：Excalidraw 的 E2EE 机制（房间号公开 + 密钥**只在 URL fragment**、
  服务端零知识，官方文档转述原文）；M3 调研结论（**零知识与审批路由不相容** ——
  本 ADR 决定 2 的分层就是它）。

## 背景

同步中继要"看得见路由信息"（它是协调器，V5 §4），而用户的内容（文本、画布节点、
工具参数与结果）不该被中继看见。这两件事**同时**成立的办法不是"全加密"，
而是**分层**。

## 决定

### 1. 机制：房间号公开 + 密钥 fragment

```
https://<中继>/r/<房间号>#<密钥>
                    ↑        ↑
              公开（路由用）  按 HTTP 语义**从不发给服务端**
```

- 房间号 = 同步流 id（中继靠它路由）；
- 密钥 32 字节，只在 fragment / 内存里；**`parseRoomLink` 只从 fragment 取**
  （有人塞进 `?key=` 取不到 —— query 会进服务端日志，等于没加密，测试钉着）。

### 2. 两层：内容加密、控制明文（**这是取舍，不是疏漏**）

| 层 | 事件 | 中继看得见 |
|---|---|---|
| 内容层（加密） | 文本、画布/节点内容、工具参数与结果 | 密文 + 长度 |
| 控制层（明文） | 审批、接管、邀请、取消、（接管）claim | 类型 + 路由信息（当事人、待谁批） |

理由（M3 的结论）：**零知识与审批路由不相容**。全加密的话中继没法履行协调职责
（路由给谁、谁接管、超时怎么算）—— 而"中继承担协调职责"是 V5 §4 的明文口径。

⚠️ **明文的控制事件不许塞内容正文**（"审批那一件的事"该走内容层）——
名单（`CONTROL_EVENT_TYPES`）与这条纪律都写在代码注释里；加新类型要过一遍
"中继需不需要据它协调"这个问题。

### 3. 算法用 WebCrypto 的 AES-256-GCM，**每条一个随机 IV**

`globalThis.crypto.subtle` 在 Node 19+/Electron/Bun 都有：零依赖、标准件
（**自己写密码学是本项目的红线**）。`sealContent` **不接 IV 参数** ——
GCM 同密钥复用 IV 是灾难级错误，这里不给调用方犯错的机会。

解不开（密钥错 / 密文被改）时**抛**，**不返回乱码**：上层把乱码当内容显示出去，
比"解不出来"糟得多。

### 4. 中继那条流里"密文与明文长得一样"

中继不解释 `payload`（2.1 起就是这样）—— 所以这一层**不需要中继配合**：
加密是发送端与接收端之间的事，中继照旧只搬字节。测试用**真推给中继**证明零知识：
把密文推进去、拉出来，那一整段 JSON 里找不到任何明文子串。

## 明确不做的

- **不做"全加密"**（连控制事件也加密）：中继会退化成哑管道，与"中继承担协调职责"冲突
  （见决定 2）。要全加密就得把协调搬到客户端（另一套协议），那是 V6+ 的事。
- **不自造算法 / 不做密钥托管**：密钥丢了就是丢了（端到端加密的定义）。
  想"忘密码也能恢复"是另一个产品（服务端托管密钥），与 E2EE 互斥，不在这里做。
- **不加密中继的路由元数据**（谁发的、什么时候、多长）：那是它履行协调职责的前提；
  它泄露的是"通信模式"，不是内容 —— 这条边界如实写在这里。

## 后果

- 内容过中继**零知识**；控制事件照旧能让中继协调（审批流转不受加密影响，测试钉着）。
- 这一层是**纯函数 + 标准件**，不与中继实现耦合：换成别的传输（直连 / 别的中继）
  照样用。
- 已知边界（如实记）：密钥轮换未做；大内容（引用通道那份本体）的加密未定；
  界面上还没有"这是加密房间"的标识；中继仍看得见通信模式（流量分析**不在**防护范围）。
