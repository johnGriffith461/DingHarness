# 故障排查

> 原则：**先看它自己说什么**。`ding doctor`、审批卡、留痕行都在说人话；
> 猜之前先读。下面是按症状排的索引。

## 启动

| 现象 | 先查 | 下一步 |
|---|---|---|
| 桌面白屏 / 没有窗口 | 终端里 `pnpm dev` 的报错 | 开发态缺产物时跑 `pnpm electron:build`；打包版看安装目录是否完整 |
| `pnpm start` 说产物过期 | 源码比产物新 | `pnpm build`（或 `pnpm build:web` + `pnpm electron:build`） |
| 端口连不上（`ECONNREFUSED`） | 是否已有实例在跑 | 关掉残留进程；调试端口换一个 |
| CLI 报"不认识的子命令" | 拼写 / 版本 | `ding --help`；安装包版本用 `ding --version` 核对 |

## 模型与凭据

| 现象 | 真因 | 下一步 |
|---|---|---|
| `doctor` 说一条 key 都读不到 | 没配 / 配错段 | `ding init`；手写时键必须在 `refs:` **下面一层**、缩进 |
| 配了 key 仍说没有 | 环境变量与凭据文件都没命中 | 用 `--provider` 指定另一家；`ding providers list` 看 keyRef |
| `DSH_NO_REAL_MODEL` 拒绝远程 | 零出网闸开着 | 这是有意为之：只在本地假服务上跑，或显式取消该环境变量 |
| 桌面设置里填的 key 重启没了 | 系统加密不可用 | 桌面会拒绝写并说明；看 `ding doctor` 的「凭据保护」 |

## 工具与权限

| 现象 | 真因 | 下一步 |
|---|---|---|
| 写文件被拒 | 目标不在工作目录 | `--dir` 指到该目录；桌面在工作区里授权 |
| 一直停在"等你确认" | 档位是每步确认 / 有待批 | 桌面看审批卡；CLI `ding sessions --state <id>` |
| 点了「总是允许」下一轮还问 | 旧版本装配漏项（已修） | 升级；规则在设置 → 通用里可查删 |
| 子智能体说"想做但没被批准" | 子智能体没有当场批的按钮 | 父级步上会出现待批行（G11），在那里批 |
| 插件调用超时 | 插件卡住 / 超过 30 秒 | 看 `ding plugins list` 的隔离档位；卡死会被终止 |

## 上下文与成本

| 现象 | 真因 | 下一步 |
|---|---|---|
| 回合很慢、上下文在涨 | 历史太长触发压缩 | 看「用量与追踪」的上下文压力；`ding fork` 开新枝 |
| 成本比预期高 | 缓存命中低 / 模型贵 | `ding sessions --cost --by model`；换模型或压历史 |
| 回复"忘了"前面说的 | 压缩丢了细节 | 把关键约束写进长期记忆，或 fork 回更早的回合 |

## 恢复与数据

| 现象 | 真因 | 下一步 |
|---|---|---|
| 崩溃之后那轮不见了 | 未完成回合 | `ding resume` 列出被打断的回合；`--continue` 重跑 |
| 想回到某一步 | —— | `ding tree` 看分支；`ding fork <id> --at-turn N` 新开一枝 |
| 想回滚某个文件 | —— | `ding review <id> --revert <路径>`（覆盖写如实不可回滚） |
| 换机器 | —— | `ding export` / `ding import`（不含密钥）；完整备份用 `ding backup` |

## 仍然不对劲

1. `ding doctor --json` 留一份；
2. 桌面「设置 → 关于 → 导出诊断包」（已脱敏；导出前请自己看一遍）；
3. 按 `.github/ISSUE_TEMPLATE/bug_report.yml` 填：**怎么重放**比"坏了"有用得多。
