# 教程：把第一件真事交给它做完

> 这篇只讲**一条能走通的路**。每步都写了「你会看到什么」——如果看到的不一样，
> 先看文末的「卡住了」，不要去猜。

## 0. 你需要的

- 一个可用的模型通道（OpenAI 兼容 / Anthropic / DeepSeek / 本地网关都行）；
- 一个**专门的空目录**当工作区（第一次别拿正在开发的项目试）；
- 桌面版（`pnpm dev` 或安装包）**或** CLI（`npm i -g ding-harness`，或源码 `pnpm ding`）。

## 1. 让它认识你的模型（2 分钟）

**桌面**：首次启动会出现四步向导 —— 选 provider → 填 key → 选模型与工作区 → 选权限档。
key 走主进程加密落盘，不写进浏览器存储。

**CLI**：

```bash
ding init
ding doctor
```

`doctor` 的每一项都有「下一步」。它说 key 没配，就是没配 —— 不要跳过。

## 2. 选一个**产物能验收**的任务

第一次别问"帮我写个网站"。选那种**做没做完一眼能看出来**的：

> 把 `notes/` 里三份周报合并成一份 `summary.md`，按「结论 / 数据 / 待办」三段写。

在桌面输入框里发出去之前，先看一眼工具栏：

| 旋钮 | 第一次建议 | 为什么 |
|---|---|---|
| 工作目录 | 那个空目录 | 它只能在这个目录里读写 |
| 权限档 | **按需确认** | 写文件 / 跑命令会停下来等你点；先看清它想干什么 |
| 模型 | 任一可用模型 | 这一步不考模型强弱 |

CLI 等价：

```bash
ding run "把 notes 里三份周报合并成 summary.md，按结论/数据/待办三段写" --dir ./notes-workspace --mode 按需确认
```

## 3. 中途会发生什么

1. 它先**读**目录里的文件（只读工具通常不问）；
2. 要**写** `summary.md` 时停下来，卡片上写着"写哪个文件、写什么"；
3. 你点「允许」——它才写。点「拒绝」它就得换办法，不会硬来；
4. 同一类操作如果你按了「总是允许」，之后同类不再问（规则落盘，重启仍在；
   可以随时在设置里删）。

这一步是产品最重要的承诺：**闸门不是装饰**。如果它没问就写了，那是缺陷，不是"智能"。

## 4. 验收（别只看它说"完成了"）

- 桌面：打开产物卡片，或在工作区里看文件；
- 桌面「逐文件审阅」：每个文件的 diff 与回滚；
- CLI：

```bash
ding sessions                 # 找到刚才那轮
ding review <会话 id>         # 逐个文件看改了什么
ding review <会话 id> --revert <路径>   # 不满意就回滚这一个文件
```

把它写的 `summary.md` 打开读一遍。**读起来不对就回滚**——回滚也是这套东西的一部分。

## 5. 让它接着干（同一段上下文）

- 桌面：直接在同一个对话里说"第二段数据不够，回去补上"；
- 想另开一条不污染当前对话：`ding fork <会话 id> --at-turn 2 --into try-2`；
- 想让它在你关掉界面之后继续跑：`ding run "…" --background`，然后 `ding jobs`。

## 6. 下一次可以试的

- 打开命令面板（默认 `Ctrl/Cmd + K`），输入「用量」看这一轮花了多少；
- 设置 → 通用 → 个性化：换主题、改快捷键、给它一个称呼；
- 想让它记住长期偏好：设置 → 记忆，或在对话里明确说"记住：以后先给结论"。

## 卡住了

| 你看到的 | 真因 | 下一步 |
|---|---|---|
| `doctor` 说连不上 provider | key / baseURL / 网络三者之一 | 按它给的那一项改；`--provider` 指定另一家 |
| 写文件被拒 | 目标不在工作目录 | `--dir` 指到那个目录；别用绝对路径越界 |
| 一直停在"等确认" | 权限档是每步确认 / 有待批的卡片 | 桌面看审批卡；CLI `ding sessions --state <id>` |
| 回复很慢且上下文在涨 | 历史太长触发压缩 | 看「用量与追踪」的上下文压力；可以 `ding fork` 开新枝 |
| 想回退到某一步 | —— | `ding fork <id> --at-turn N` 新开一枝，原会话不动 |

## 一条硬边界（先知道，少踩坑）

插件跑在**独立进程**里（G18）：崩溃/死循环只毁它自己；读写文件、起子进程按你批准的权限受限。
但 **`net` 仍拦不住** —— 插件联网要如实声明。装之前看清权限清单；
别把"未签名"当成"有问题"，也别把"已签名"当成"安全"。
