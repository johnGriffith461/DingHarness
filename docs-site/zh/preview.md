# 内置浏览器预览

agent 改完本地页面（dev server / 静态服务）之后，在应用内直接把页面打开看一眼，
不用切到系统浏览器。

## 用

1. 起你的本地服务（例如 `npm run dev`，监听 `localhost:3000`）；
2. 桌面 →「创作广场」→ 顶部「打开预览」→ 填 `http://localhost:3000`。

- **独立窗口**：不挤占对话区；
- **持久分区**（`persist:preview`）：cookie/localStorage 跨次保留 —— 需要登录的页面
  登录一次就一直在；同时与主应用的会话隔离，预览页拿不到应用凭据；
- 再次打开会**复用**同一个窗口并导航到新地址。

## 安全边界（不装）

| 规则 | 为什么 |
|---|---|
| **只允许本机地址**（`localhost` / `127.0.0.1` / `::1` / `*.localhost`） | 这个入口会被 agent 触达；预览窗口不该变成任意网页浏览器 |
| `nodeIntegration:false` + `contextIsolation:true` + `sandbox:true` | 预览的是"别人的页面"，不能给它 Node |
| 新窗口一律拒 | 弹窗/`target=_blank` 要么在同窗口导航（仍受本机限制），要么交给系统浏览器 |
| 外链跳转交给系统浏览器 | 明确区分"预览"与"上网" |

## 边界

- 不做多标签/开发者工具面板（要调试用系统浏览器）；
- 不做截图/元素选择（那是 Computer Use 的事）；
- 只预览 http(s)；`file://` 的静态页请起一个本地静态服务（`python -m http.server`）。
