# 电脑操作（Computer Use）

让 Ding 截屏、移动鼠标、点击、输入，用来操作**没有 API 的桌面应用**。
默认关闭；打开之后，**每一次动作都要批准**，且全程留痕。

## 打开

桌面 →「权限矩阵」页 → 电脑操作 → **授权电脑操作…**（主进程弹原生确认）。
随时可以关；关掉之后所有动作立即拒绝。

## 能做什么

| 动作 | 工具名 | 说明 |
|---|---|---|
| 截屏 | `computer_screenshot` | 截主屏，返回落盘路径与尺寸（面板里可预览） |
| 点击 | `computer_click` | 屏幕坐标 (x, y)，左/右键 |
| 输入 | `computer_type` | 一段文字（≤4000 字符；走剪贴板粘贴，支持中文） |
| 按键 | `computer_key` | 白名单：enter/tab/escape/方向键/ctrl+a… |

agent 与面板都能触发；两条路都经过同一套校验与留痕。

## 三层门（缺一不可）

1. **授权**：`computer-use.json` 的 `enabled`，默认 false；
2. **审批**：面板发起 → 每次弹原生确认；agent 发起 → 工具闸门（策略表里是 `write`，
   按需确认档下会停下来问）；
3. **留痕**：成功、失败、被拒都写 `computer-use.jsonl`；**输入的文字不记录**（只记字符数）。

## 限制（不是沙箱）

- 坐标必须在主屏范围内；按键白名单；单次输入 ≤4000 字符；
- **这不是操作系统级沙箱**：一旦批准，动作作用在你的真实桌面上（你能点的它就能点）；
- 只实现了 **Windows**（user32/SendKeys）。macOS 的无障碍树路线**未做**，
  不写一个跑不起来的壳；
- 不做"只许操作某个窗口"的隔离 —— 那需要 OS 级手段，不假装有。

## 建议

- 用白名单式的提示词（"打开记事本，输入今天日期"），别让它自由发挥；
- 敏感窗口（银行/密码管理器）不要开着让它操作；
- 不用的时侯把授权关掉。
