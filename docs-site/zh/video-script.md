# 5 分钟演示脚本（拍摄用）

> 目标：让第一次看到它的人明白三件事 —— **它真能干活、它停下来问你、它记得住**。
> 全场不用剪掉的失败镜头；演示失败就照实说"这条现在不行"。

## 准备（不录）

- 用一个全新的数据目录 + 一个空工作区，避免把真实会话录进去；
- 模型选一个稳定、快的；
- 权限档放在**按需确认**（这集的卖点就是"它会停"）；
- 关掉通知与无关窗口；把字号调到 110%。

## 镜头表

| 时间 | 画面 | 旁白 | 操作 |
|---|---|---|---|
| 0:00–0:20 | 桌面全貌 | "这是一个本地优先的 agent 工作台。它在你的机器上读写文件、跑命令 —— 每一步都能停下来问你。" | 鼠标轻扫左栏与输入区 |
| 0:20–0:50 | 工作区 | "先给它一个目录。它只能在这里面动东西。" | 点工具栏工作目录，选 `demo` |
| 0:50–1:40 | 第一轮任务 | "任务选能验收的：把三份中文笔记合并成一份摘要。" | 输入任务 → 发送 |
| 1:40–2:10 | **审批卡**（本集核心） | "它要写文件了 —— 停在这里。它想写什么、写去哪里，都在卡片上。我点允许，它才写。" | 先停 3 秒不点，再点「允许」 |
| 2:10–3:00 | 产物 + 审阅 | "写完不是结束。逐文件审阅能看到改了什么；不满意可以只回滚这一个文件。" | 打开审阅面板 → 展开 diff |
| 3:00–3:40 | 命令面板 | "找功能不用翻菜单。Ctrl+K，输入'用量'。" | Ctrl+K → 输入 → 回车 |
| 3:40–4:20 | 个性化 | "主题、快捷键、它怎么称呼你 —— 都在设置里。人格只影响说话方式，不改排版。" | 设置 → 通用 → 改称呼 |
| 4:20–4:50 | 诚实边界 | "两件事必须说清：插件 v1 和主程序同进程，资源类权限拦不住；基准数字只对本机这次负责。" | 切到「诚实边界」页 |
| 4:50–5:00 | 收尾 | "装好、跑通、能回退。这就是它的全部承诺。" | 回到首页 |

## 台词要点（别背稿，记住三句）

1. **"它停下来问你了"** —— 每次审批卡出现，都停 2–3 秒再点；
2. **"这只是其中一个文件，可以只回滚它"** —— 强调粒度；
3. **"这一条现在不行"** —— 遇到失败镜头直接说，不剪。

## 不要做的事

- 不要演示"全自动改完一整个仓库"：那会让人以为闸门可以关掉走人；
- 不要报任何 benchmark 百分比，除非屏幕上就是**这次**跑出来的输出；
- 不要把插件演示成"安全的"：v1 同进程是已知边界，说了反而更可信。

## 备用镜头（主线卡住时切）

- `ding tree`：一个会话分叉成两枝（回退不丢历史）；
- `ding jobs`：后台任务跑完，日志在；
- 桌面「电脑操作」：让它在记事本里写一句话（记录下审批过程）。
